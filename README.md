A one-line museum placard for an ordinary office stapler, written as if it were an ancient ritual binding device dug from a lost civilisation — catalogue date, material, and donor included. A dry-witted curator judge compares placards head to head; one winner takes the $2 reward.

## Run it

```sh
python3 main.py
```

Writes the placard to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
